01 / THE REASON

One small gap.
A very real one.

I wanted a Markdown editor that felt truly portable between Mac and Windows. I looked around and couldn't find one that fit.

The options often came with a setup step, a platform-specific app, an account, or files tied to one machine. I wanted something simpler: a writing tool I could carry on a USB drive, open on either system, and use without installing software or creating an account.

So I made Wick: a small, self-contained editor that runs in a browser. It is an independent project by olympus_mons26.

02 / UNDER THE HOOD

Simple tech.
Clear trade-offs.

Wick is built with plain HTML, CSS, and JavaScript. There is no app framework, build step, backend, or network service hidden underneath. The whole app is a folder you can carry and inspect.

Auto-save real files

After the one-time folder permission, Wick writes each edit to its regular Markdown file in your selected folder. This uses the File System Access API, currently available in Chromium-based browsers. Other browsers use browser storage plus Import/Export.

03 / THE PRACTICAL GUIDE

From download
to first note.

Wick is a folder, not a traditional installer. Pick it up, open it in a browser, and keep a backup of the notes you want to take along.

01 / SET UP

Install Wick
without installing.

Download the ZIP and extract the Wick folder somewhere convenient: your desktop, a USB drive, or another folder you can access.

  1. 1

    Get the files. Use Download Wick or visit the GitHub repository.

  2. 2

    Open it. On macOS, double-click Start-Wick-onMac.command. If macOS reports an access-privileges error, open app/index.html directly in a browser. If a security warning appears, Control-click the launcher and choose Open. On Windows, double-click Start-Wick-onWindows.bat.

  3. 3

    Choose your notes folder once. In the app, choose Choose /notes folder and select the root-level notes folder on the USB drive (or another folder). Grant write access when the browser asks. No runtime, account, server, or network connection is needed.

↔

Connect the folder on each computer. The app remembers the permission when the browser allows it. If not, reconnect the folder after opening Wick. In browsers without folder access, use Import/Export or Backup.

02 / NOTES

Add, write,
save, and remove.

＋

Make a note
Choose New, enter a name, and start writing. Wick creates an untitled starter note the first time it opens.

⌁

Save as you type
Select the root-level notes folder once. Wick auto-saves each edit in the background to the matching .md file—no page reload for each keystroke. Use Ctrl/⌘ + S to save immediately. Without folder access, it auto-saves to browser storage instead.

↓

Keep or move a copy
With a connected folder, Markdown notes are already ordinary files on that drive. Export downloads the open note; Backup bundles your library for transfer or safekeeping.

×

Rename or delete
Use the matching top-bar button. In folder mode, rename and delete update the real file too. Delete asks for confirmation. Export or back up important notes before removing them.

↔

Make room
Use Hide Notes beside Editor to collapse the file list. Editor and Preview scroll together in either direction; on a narrow screen, they stack vertically.

Direct folder writing requires a browser with the File System Access API (currently Chromium-based browsers) and your explicit permission. Other browsers retain the import/export workflow.

03 / MAKE IT YOURS

Customize Wick
to your taste.

Use the theme button in the editor to switch between light and dark. Theme choice is remembered by the browser alongside your current note.

Want to change the look? Open the files in a text editor:

  • app/css/app.css — editor layout, colors, and typography.
  • app/index.html — labels, toolbar, and interface structure.
  • app/js/app.js — note actions, autosave, and shortcuts.

Wick has no build step or package dependencies. Keep a copy before editing; changes to app files won't change your notes stored in the selected folder.
